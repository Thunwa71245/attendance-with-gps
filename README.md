# attendance-with-gps📌 QR Code Attendance System

ระบบเช็คชื่อฝึกงานด้วย QR Code + GPS + Google Sheets

โปรเจคนี้เป็น Web Application สำหรับใช้ตรวจสอบเวลาเข้าเรียนหรือเข้างานของนักศึกษา โดยผู้ใช้งานสามารถสแกน QR Code ภายในพื้นที่ที่กำหนด แล้วกรอกข้อมูลเพื่อเช็คชื่อ ระบบจะบันทึกข้อมูลลง Google Sheets อัตโนมัติ พร้อมคำนวณสถานะการมาทำงาน

ระบบถูกออกแบบให้มีโครงสร้างเรียบง่าย ใช้งานง่าย และสามารถขยายระบบได้ในอนาคต

## 📋 คำอธิบายข้อมูลและการทำงาน

### ข้อมูลมาจากไหน?
- **นักศึกษา:** ข้อมูล ID และชื่อมาจากการล็อกอินครั้งแรก เก็บใน localStorage ของเบราว์เซอร์
- **การเช็คชื่อ:** เวลาและวันที่มาจากเวลาที่สแกน QR Code บนอุปกรณ์
- **ตำแหน่ง:** พิกัด GPS มาจาก GPS ของอุปกรณ์ (ถ้ามี)
- **ห้อง:** ข้อมูลห้องมาจาก QR Code ที่สร้างโดยอาจารย์
- **สถานะ:** คำนวณอัตโนมัติจากเวลาที่เช็คชื่อเทียบกับเวลาเริ่มงาน

### การใช้งานจริงข้อมูลนี้เอาไปทำอะไรได้บ้าง?
1. **ติดตามการเข้า-ออกงาน:** ตรวจสอบว่าพนักงาน/นักศึกษามาทำงานตรงเวลา
2. **คำนวณอัตราการเข้าเรียน:** คำนวณเปอร์เซ็นต์การเข้าเรียนรายเดือน
3. **ตรวจสอบการมาสาย:** บันทึกเวลาที่มาสายและระยะเวลาที่มาสาย
4. **วิเคราะห์พฤติกรรม:** ดู pattern การเข้า-ออกงานของแต่ละคน
5. **รายงาน:** สร้างรายงานสรุปสำหรับ HR หรืออาจารย์
6. **การแจ้งเตือน:** สามารถแจ้งเตือนเมื่อมีคนมาสายหรือไม่มา

### เงื่อนไขที่ใช้ในการคำนวณ
- **เวลาเริ่มงาน:** กำหนดได้ในหน้า Config (default: 08:00)
- **เวลาปิด:** กำหนดได้ในหน้า Config (default: 09:00)
- **เวลามาสาย:** กำหนดได้ในหน้า Config (default: 15 นาทีหลังเวลาเริ่ม)
- **ระยะทาง:** กำหนดได้ในหน้า Config (default: 50 เมตร)
- **วันที่ทำงาน:** กำหนดได้ในหน้า Config (default: จันทร์-ศุกร์)

## 🏗️ โครงสร้างระบบ

### ไฟล์หลัก
- `login.html` - หน้าล็อกอินสำหรับนักศึกษา
- `scan.html` - หน้าสแกน QR Code และกรอกข้อมูล
- `dashboard.html` - แดชบอร์ดแสดงสถิติการเข้า-ออกงาน
- `config.html` - หน้าตั้งค่าระบบ
- `api-config.js` - การตั้งค่า API และฟังก์ชันเชื่อมต่อ

### API และฐานข้อมูล
ระบบใช้ **Google Apps Script** เป็น API และ **Google Sheets** เป็นฐานข้อมูล

#### โครงสร้างตารางแนะนำ:
1. **ตารางนักศึกษา (Students):**
   - Student ID
   - Name
   - Department
   - Created Date

2. **ตารางการเช็คชื่อ (Attendance):**
   - Student ID
   - Name
   - Room
   - Date
   - Check-in Time
   - Status (On-time/Late)
   - Latitude
   - Longitude
   - Distance from room

#### การใช้ API เดียวกันหรือแยก?
**แนะนำใช้ API เดียวกัน** แต่มี parameter `action` เพื่อเลือกตาราง:
- `?action=verify_student` - ตรวจสอบนักศึกษา
- `?action=submit_attendance` - ส่งข้อมูลการเช็คชื่อ
- `?action=get_dashboard` - ดึงข้อมูลแดชบอร์ด
- `?action=add_student` - เพิ่มนักศึกษาใหม่

### ข้อผิดพลาดที่อาจเกิดขึ้น
1. **API URL ไม่ถูกต้อง:** ตรวจสอบในหน้า Config
2. **CORS Error:** Apps Script ต้องตั้งค่าเป็น "Anyone"
3. **GPS ไม่ทำงาน:** บนอุปกรณ์บางตัวอาจต้องอนุญาตการเข้าถึงตำแหน่ง
4. **QR Code อ่านไม่ได้:** ตรวจสอบกล้องและแสง
5. **ข้อมูลไม่บันทึก:** ตรวจสอบการเชื่อมต่ออินเทอร์เน็ต

## 🚀 การติดตั้งและใช้งาน

### 1. ตั้งค่า Google Apps Script
1. สร้าง Google Sheet ใหม่
2. ไปที่ Extensions > Apps Script
3. คัดลอกโค้ดจาก `google-apps-script.js`
4. Deploy เป็น Web App และอนุญาต "Anyone"

### 2. ตั้งค่า Config
1. เปิด `config.html`
2. ใส่ GAS URL ที่ได้จากข้อ 1
3. ปรับแต่งค่าอื่นๆ ตามต้องการ

### 3. เริ่มใช้งาน
1. นักศึกษาล็อกอินที่ `login.html`
2. สแกน QR Code ที่ `scan.html`
3. ดูข้อมูลที่ `dashboard.html`
